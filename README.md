# 🏫 School Guide

> An educational guidance platform designed to help students discover, organize, and access useful learning resources.

[![GitHub](https://img.shields.io/badge/GitHub-FedaaSameh-181717?style=for-the-badge&logo=github)](https://github.com/FedaaSameh)
[![Education](https://img.shields.io/badge/Focus-Education-blue?style=for-the-badge)](https://github.com/FedaaSameh/School-Guide)

## 🚀 Overview

School Guide focuses on making educational resources easier to discover and navigate by organizing useful learning content in one place.

## ✨ Features

- 📚 Educational resources
- 🎥 Learning content
- 🧭 Student guidance
- 🔎 Resource discovery
- 📂 Organized categories
- 🎯 Learning paths
- 📱 Responsive design
- 🌙 Dark / Light Mode
- 🌐 Arabic / English support

## 🗂️ Resource Categories
